# Create an Request

Follow these steps to create a new Request in GatherMonk.

## Step 1: Open Requests

From the GatherMonk dashboard, select **Requests** from the main navigation.

## Step 2: Create a New Request

Click **Create Request**.

Enter the required Request information:

- Request name
- Request date
- Start time
- End time
- Location
- Request description

## Step 3: Configure the Request

Configure the Request settings according to your requirements.

## Step 4: Save

Click **Create Request** to save the Request.

Your new Request will appear in the Requests list.

<Tip>
Make sure the Request date and time are correct before publishing the Request.
</Tip>
