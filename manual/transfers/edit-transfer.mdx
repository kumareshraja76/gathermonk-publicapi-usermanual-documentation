# Chapter 14: Editing a Transfer

To modify a transfer after it has been sent, click the **Edit** (pencil) icon on the transfer row. You can update the transfer name, add or remove files, adjust the expiry date, and change security settings. Edited transfers retain the same download link.

![Edit Transfer — update files, recipients, and settings](/manual/help-guide/img_p44_1.png)

> ℹ️ **Note:** Removing a file from an active transfer immediately removes it from the download page. Recipients who have already downloaded the file retain their copy.
