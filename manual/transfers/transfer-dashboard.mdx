# Chapter 12: The Transfers Dashboard

**Transfers** is GatherMonk's secure file-sending module. Use it to deliver files to clients, colleagues, or vendors — with full control over access, expiry, and download notifications.

![Transfers dashboard — list of all active transfers with recipient, expiry, downloads, and status](/manual/help-guide/img_p39_1.png)

The Transfers dashboard lists every transfer you have created with the following columns:

- **Name / Files** — transfer name and number of files included
- **Recipients** — the email address(es) the transfer was sent to
- **Expires** — the date the transfer link becomes inactive
- **Downloads** — how many times the files have been downloaded
- **Status** — Active or Expired
- **Actions** — Edit (pencil), Duplicate (copy), Delete (bin)

Click **Create new transfer** in the top right to send files.
