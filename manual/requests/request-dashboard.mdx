# Chapter 1: The Requests Dashboard

The **Requests dashboard** is your central hub for all active, draft, and completed document collection requests. Access it by clicking **Requests** in the main navigation.

![Requests dashboard — empty state with Start New Requests button](/help-guide/img_p4_1.png)

When no requests have been created yet, the dashboard displays an empty state with a prominent **Start New Requests** button. Once requests are live, each one appears as a card showing its name, status, recipient count, submission progress, and due date.

> 💡 **Tip:** Use the search and filter options to quickly locate a specific request when you have many running simultaneously.
