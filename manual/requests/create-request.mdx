# Chapter 2: Creating a Request

GatherMonk uses a guided 5-step wizard to build requests: **Choose Type → Information → Builder → Preview → Finalize**. Click **Start New Requests** or **+ Create Request** to begin.

---

### Step 1 — Choose Type

The first step presents GatherMonk's library of **4,000+ ready-made templates** filtered by Industry, Category, Type, and Role. Templates include lead qualification forms, onboarding packs, compliance documents, surveys, and more.

![Step 1 — Choose Type: browse and filter 371+ ready-made templates](/manual/help-guide/img_p6_1.png)

To use a template, click **Use Template** on any card — the builder will be pre-populated with that template's fields. To build from scratch, click **Next** without selecting a template.

---

### Step 2 — Information

Give your request a name, a header title (shown to recipients), a rich-text header description (explaining what you need and why), and any supporting file attachments you want recipients to reference.

![Step 2 — Information: set the request name, title, description, and attachments](/manual/help-guide/img_p7_1.png)

The header description editor supports bold, italic, lists, links, font size, and colour. When done, click **Save & Next**.

---

### Step 3 — Builder

The **Builder** is GatherMonk's drag-and-drop form editor. The left panel lists all fields in the request; the right panel shows the selected field's settings. Click any field on the left to edit it on the right.

![Step 3 — Builder: drag-and-drop editor with field list on the left](/manual/help-guide/img_p8_1.png)

Each field has a **Label**, a **Required** toggle, and a **Show Instruction** toggle. You can reorder fields by dragging them in the left panel. Use **Add a Page** to split a long request into multiple sections.

![Selecting a field type in the Builder](/manual/help-guide/img_p9_1.png)

![Builder — field configuration panel](/manual/help-guide/img_p10_1.png)

#### Supported Field Types

- **Short Text** — Single-line text input for names, IDs, short answers
- **Long Text / Paragraph** — Multi-line text area for descriptions, bios, or comments
- **Email** — Validated email address field
- **Dropdown** — Single-selection from a list of options
- **Multiple Choice** — Radio-button style single selection
- **Checkboxes** — Multi-select from a list of options
- **Date** — Calendar picker (past or future only)
- **File Upload** — Supports PDF, PNG, JPG, DOCX, etc. with size and dimension limits
- **Signature** — Digital signature field
- **Rich Text / Instructions** — Static display text between fields
- **Section Divider** — Visual separator to group fields

---

### Step 4 — Preview

Before publishing, preview exactly what recipients will see. Check that all fields appear in the correct order, labels are clear, and instructions are complete.

![Step 4 — Preview: see the request exactly as recipients will see it](/manual/help-guide/img_p12_1.png)

---

### Step 5 — Finalize

Configure **Communication Schedule**, **Visibility**, **Due Date**, and whether to save the request as a reusable template.

![Step 5 — Finalize: communication schedule, visibility, due date, and template options](/manual/help-guide/img_p13_1.png)
