# Chapter 10: Sharing a Form

Once a form is published, share it with respondents using the Share options. Click the **Share** icon on any form card.

![Form sharing options — link, embed code, and QR code](/manual/help-guide/img_p36_1.png)

GatherMonk provides three ways to share a form:

- **Direct link** — a URL you can paste into any email, message, or social post
- **Embed code** — an HTML snippet to embed the form directly into any web page
- **QR code** — scannable code for print materials, signage, or event badges
