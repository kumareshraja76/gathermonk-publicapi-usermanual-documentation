# Chapter 8: The Forms Dashboard

The **Forms module** is for capturing structured data from respondents without requiring file uploads. It is best suited for registration forms, surveys, feedback questionnaires, and lead capture.

Access Forms from the main navigation. Each form appears as a card showing the form name, submission count, and publish status.

![Forms dashboard](/manual/help-guide/img_p32_1.png)

![Forms dashboard with submission count and action buttons](/manual/help-guide/img_p34_1.png)

Each form card shows:

- **Form name** — the internal title you gave the form
- **Submissions count** — number of responses received
- **Status** — Published or Draft
- **Actions** — Edit (pencil), Delete (bin), Share (arrows), Open (arrow-out)
