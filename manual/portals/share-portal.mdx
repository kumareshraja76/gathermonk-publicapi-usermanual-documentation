# Chapter 21: Sharing the Portal

Share the portal with clients and embed it on your website using the Share options.

![Portal share options — link, QR code, and embed](/manual/help-guide/img_p58_1.png)

GatherMonk provides three ways to share a portal:

- **Share via Link** — copyable URL for the client portal login page
- **Share via QR Code** — scan to access the portal login page
- **Embed in a Website** — HTML snippet to embed the portal in any web page

![Portal share link — copyable URL for the client portal login page](/manual/help-guide/img_p59_1.png)

![Portal embed code — HTML snippet to embed the portal in any web page](/manual/help-guide/img_p60_1.png)
