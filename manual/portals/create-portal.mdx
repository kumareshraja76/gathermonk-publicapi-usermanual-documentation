# Chapter 16: Creating a New Portal

Click **+ Create new portal** from the Portals dashboard to set up a new client workspace.

![Create new portal — naming and initial setup](/manual/help-guide/img_p48_1.png)

Give the portal a name (e.g. "Acme Corp Client Hub") and an optional description. After creation, you are taken to the portal's admin view where you can configure branding, add clients, attach requests, and build guides.

![Portal overview — admin view of a newly created portal](/manual/help-guide/img_p49_1.png)

> 💡 **Tip:** Name portals descriptively — include the client or project name — so you can identify them at a glance from the Portals dashboard.
