# Chapter 19: Requests Inside the Portal

Attaching requests to a portal makes them visible to the relevant clients directly inside their portal workspace — no separate email link needed.

![Portal Requests tab — requests attached to this portal](/manual/help-guide/img_p53_1.png)

---

### Adding a Request to the Portal

Click **Add Request** (or the **+** icon) to link an existing request to the portal.

![Adding a request to the portal](/manual/help-guide/img_p54_1.png)
