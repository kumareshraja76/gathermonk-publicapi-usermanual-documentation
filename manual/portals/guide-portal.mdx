# Chapter 20: Guides

Guides are rich-text instruction pages that live inside the portal alongside requests and tasks. Use them to replace lengthy briefing emails.

![Portal Guides tab — list of all guides in the portal](/manual/help-guide/img_p55_1.png)

---

### Creating a Guide

Click **Create Guide** and use the rich-text editor to write your guide. Guides support formatted text, embedded images/videos, and downloadable attachments.

![Creating a new guide — rich-text editor with image, video, and file attachment support](/manual/help-guide/img_p56_1.png)

---

### Editing a Guide

Click any guide to edit its content. Changes are saved and immediately visible to clients after publishing.

![Editing an existing guide](/manual/help-guide/img_p57_1.png)
