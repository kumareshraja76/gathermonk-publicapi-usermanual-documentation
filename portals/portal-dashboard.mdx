# Chapter 15: The Portals Dashboard

The **Client Portal** brings everything together into a single branded workspace where clients see all requests, files, and guides assigned to them.

![Portals dashboard — active portal count, total clients, and portal cards](/help-guide/img_p47_1.png)

The Portals dashboard shows three summary metrics at the top:

- **Active portals** — number of live portals
- **Total clients** — combined client count across all portals
- **Avg completion** — average request and task completion rate across active portals

Each portal card displays the portal name, description, overall completion percentage, and counts for Clients, Requests, and Overdue items.
