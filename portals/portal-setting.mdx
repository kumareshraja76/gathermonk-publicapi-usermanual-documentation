# Chapter 17: Portal Settings & Overview

### Portal Settings

Click the **Settings** option inside a portal to configure branding and access.

![Portal Settings — branding, subdomain, notifications](/help-guide/img_p50_1.png)

From Settings you can:

- Upload a logo and set **brand colours** for the portal
- Configure the portal subdomain or map a custom domain
- Set a welcome message displayed to clients on login
- Manage notification preferences

---

### Portal Overview / Edit

The portal overview is the first thing clients see after logging in. Edit it to include a welcome message, programme overview, key dates, or context.

![Editing the portal overview](/help-guide/img_p51_1.png)
