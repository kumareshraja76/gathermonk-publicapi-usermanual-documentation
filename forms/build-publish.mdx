# Chapter 9: Building & Publishing a Form

Forms are built using the same drag-and-drop field editor as Requests. Add questions, dropdowns, text areas, date fields, and file upload inputs. Each field supports **Required** and **Show Instruction** toggles.

---

### Publish Controls

The **Publish & Controls** panel lets you:

- Toggle the form between **Draft** and **Published**
- Set a response limit or close date
- Configure submission confirmation messages
- Manage notification preferences for new submissions

![Form publish controls — toggle publish state and configure form settings](/help-guide/img_p35_1.png)

> 💡 **Tip:** Keep a form in Draft while building and testing it. Switch to Published only when it is ready to share.
