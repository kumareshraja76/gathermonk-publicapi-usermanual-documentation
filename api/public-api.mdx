# GatherMonk Public API Documentation

This document describes the public batch ingestion and processing endpoints exposed by [routes/publicapi.php](file:///var/www/gathermonk/api-gathermonk/routes/publicapi.php).

---

## 1. Overview & Base URLs

All public API routes are prefixed under `/publicapi`:

| Environment           | Base URL                     | Public API Ingestion Endpoint                 |
| :-------------------- | :--------------------------- | :-------------------------------------------- |
| **Live / Production** | `https://api.gathermonk.com` | `https://api.gathermonk.com/publicapi/create` |

### Supported Endpoints

| Method | Endpoint       | Description                                                                                                                        | Content-Type          |
| :----- | :------------- | :--------------------------------------------------------------------------------------------------------------------------------- | :-------------------- |
| `POST` | `/create`      | Batch upload & creation of resources (Digital Cards, GatherMonk Forms, Guidebooks, Microsites, Virtual Spaces, Portals, Transfers) | `multipart/form-data` |
| `GET`  | `/status/{id}` | Check batch execution status and retrieve created resource URLs & IDs                                                              | `application/json`    |
| `POST` | `/batches`     | _(Legacy Alias)_ Identical to `/create`                                                                                            | `multipart/form-data` |

---

## 2. Authentication & Headers

All public API endpoints require API key authentication via the `X-PUBLIC-KEY` HTTP header:

```http
X-PUBLIC-KEY: your_public_access_key_here
Accept: application/json
```

- **`X-PUBLIC-KEY`** _(Header, Required)_: The user's public access API key. This is handled by the `publicapi` middleware group ([CheckPublicUser](file:///var/www/gathermonk/api-gathermonk/app/Http/Middleware/CheckPublicUser.php)), which validates the key and automatically attaches the authenticated user to the request.
- **No `uid` in payload**: Because authentication is handled securely at the middleware layer via `X-PUBLIC-KEY`, passing `uid` in the JSON metadata payload is **not required**.

If the key is missing or invalid, the API returns:

```json
{
  "message": "Public access key missing"
}
```

_(HTTP `401 Unauthorized`)_

## 3. Batch Resource Processor Endpoints

Managed by [BatchProcessorController](file:///var/www/gathermonk/api-gathermonk/app/Http/Controllers/Api/Public/BatchProcessorController.php) and dispatched via [ResourceDispatcher](file:///var/www/gathermonk/api-gathermonk/app/Processors/ResourceDispatcher.php).

### 3.1 `POST /create` — Upload & Create Batch Resources

Uploads and processes batches of cards, GatherMonk forms, guide books, microsites (interactive pages), virtual spaces, client portals, and file transfers, alongside binary file attachments (profile photos, thumbnails, banners, brochures, audio, video).

#### Request Details

- **Method**: `POST`
- **URL**: `/publicapi/create` (or `/publicapi/batches`)
- **Headers**:
  - `X-PUBLIC-KEY: <your_public_access_key>`
  - `Accept: application/json`
- **Content-Type**: `multipart/form-data`

#### Multipart Form Fields

| Field Name          | Type              | Required | Description                                                                                                              |
| :------------------ | :---------------- | :------- | :----------------------------------------------------------------------------------------------------------------------- |
| `metadata`          | `string` (JSON)   | **Yes**  | A valid JSON string containing `resource_type` and the `batch` array of objects.                                         |
| `<file_field_name>` | `file` / `file[]` | Optional | Binary files matching the aliases defined in `file_references` (e.g., `file_field_1`, `file_field_2`, `transfer_doc_1`). |

#### Top-Level `metadata` JSON Structure

```json
{
  "resource_type": "digitalcards",
  "batch": [
    {
      /* Resource item payload */
    }
  ]
}
```

- `resource_type` (`string`, required): One of:
  - `digitalcards` — Digital business and showcase cards
  - `gather-hub` — GatherMonk: Dynamic feedback, request forms, and multi-page surveys
  - `guide_book` — Structured guides with sections, texts, and VR tours
  - `interactive_pages` — Microsites & content hubs with multi-asset sections
  - `virtualspaces` — Virtual 360 tour spaces & hotspots
  - `portal` — GatherMonk: Client Portals with linked guides and requests
  - `transfers` — GatherMonk: Secure file transfers with OTP & password protection
- `batch` (`array`, required): List of resource configurations to process.

#### Response (`202 Accepted`)

```json
{
  "batch_id": 105,
  "message": "Batch accepted for processing.",
  "data": {
    "status": "completed",
    "items": {
      "210": {
        "batch_id": 105,
        "batch_item_id": 210,
        "error": null,
        "end_url": "https://api.gathermonk.com/card/abc123xyz",
        "id": 412
      }
    }
  }
}
```

### 3.2 `GET /status/{id}` — Query Batch Status

Retrieves the processing status, execution logs, and output records for a specific batch.

#### Request Details

- **Method**: `GET`
- **URL**: `/publicapi/status/{id}`
- **Headers**:
  - `X-PUBLIC-KEY: <your_public_access_key>`
  - `Accept: application/json`
- **Path Parameters**:
  - `id` (`integer`, required): The batch ID returned by `POST /create`.

#### Response (`200 OK`)

```json
{
  "id": 105,
  "user_id": 3690,
  "resource_type": "digitalcards",
  "status": "completed",
  "file_map": [
```

### 5.2 Python 3 (`requests`)

```python
import requests
import json

BASE_URL = "https://api.gathermonk.com/publicapi"
API_KEY = "pk_live_9f8d7e6c5b4a3"

headers = {
    "X-PUBLIC-KEY": API_KEY,
    "Accept": "application/json"
}

metadata = {
    "resource_type": "transfers",
    "batch": [
        {
            "transfer_title": "Deliverables Archive",
            "description": "Project deliverables package",
            "security_type": "password",
            "password": "Securexxxxxxxxxxxxxx",
            "file_references": {
                "transfer_files": ["doc1"]
            }
        }
    ]
}

files = {
    "metadata": (None, json.dumps(metadata), "application/json"),
    "doc1": ("spec.pdf", open("spec.pdf", "rb"), "application/pdf")
}

response = requests.post(f"{BASE_URL}/create", headers=headers, files=files)
data = response.json()
print("Batch Created:", data)

# Poll status
batch_id = data.get("batch_id")
status_res = requests.get(f"{BASE_URL}/status/{batch_id}", headers=headers)
print("Batch Status:", status_res.json())
```

### 5.3 Node.js / JavaScript (`FormData`)

```javascript
const fs = require("fs");
const axios = require("axios");
const FormData = require("form-data");

async function createBatch() {
  const form = new FormData();

  const metadata = {
    resource_type: "gather-hub",
    batch: [
      {
        title: "Q4 Customer Feedback Form",
        description: "GatherMonk annual client feedback",
        fields: [
          {
            name: "rating",
            label: "Overall Satisfaction (1-5)",
            type: "select",
            options: ["1", "2", "3", "4", "5"],
            required: true,
          },
          {
            name: "feedback",
            label: "Your Thoughts",
            type: "textarea",
            required: false,
          },
        ],
      },
    ],
  };

  form.append("metadata", JSON.stringify(metadata));

  const response = await axios.post(
    "https://api.gathermonk.com/publicapi/create",
    form,
    {
      headers: {
        ...form.getHeaders(),
        "X-PUBLIC-KEY": "pk_live_9f8d7e6c5b4a3",
        Accept: "application/json",
      },
    },
  );

  console.log("Batch Accepted:", response.data);
}

createBatch().catch(console.error);
```

```php
        'Accept: application/json'
    ]
]);
```
