# Chapter 6: Deleting a Request

To permanently delete a request, open the request options and select **Delete**. A confirmation prompt will appear. Deleting a request removes all associated submissions, recipient records, and audit history — this action cannot be undone.

![Confirming request deletion](/help-guide/img_p28_1.png)

> ℹ️ **Note:** Consider setting the request status to **Closed** instead of deleting it if you want to retain the submission history for compliance or audit purposes.
