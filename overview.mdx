## Introduction

### What is GatherMonk?

GatherMonk is a comprehensive digital content experience platform. It gives organisations a single, structured workspace to collect documents and data from recipients, send files securely, and host branded client portals — eliminating the scattered email chains, shared drives, and manual follow-ups that slow teams down.

Whether you are collecting compliance documents from vendors, gathering speaker assets for a conference, running employee onboarding forms, or delivering project files to a client, GatherMonk centralises every interaction in one place.

---

### Who is this manual for?

This manual covers all four GatherMonk modules and is intended for two audiences:

* **Administrators & Operators** — team members who create requests, build forms, set up portals, manage clients, and send transfers.
* **Clients & Recipients** — external contacts who receive invitations, submit documents, and access their portal.

---

### The Four Modules

* 📋 **Requests** — Send structured document and data collection requests to unlimited recipients. Track submissions in real time and approve files field-by-field.
* 📝 **Forms** — Build standalone digital forms for registration, surveys, feedback, and qualification questionnaires. Manage all responses in a central dashboard.
* 📦 **Transfers** — Send files securely to any recipient. Set expiry dates, password-protect transfers, and link them to client portals. Up to 15 files per transfer.
* 🏢 **Client Portal** — Create branded, authenticated workspaces for clients. Assign requests, tasks, and guides. Clients log in with a one-time code — no password needed.
